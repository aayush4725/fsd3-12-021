- HTTPS -> Hyper Text Transfer Protocol

172.0.0.1 : portnumber

 - 200 -> OK
 - 201 -> Created
 - 400 -> Bad Request
 - 401 -> Unauthorized
 - 403 -> forbidden
 - 404 -> Not found
 - 500 -> Internal Server Error
